# Библиотека шаблонов экранов

Прод-верные шаблоны основных экранов `../qato/qautomator-ui`, замороженные из живого Storybook.
**Идентичны продакшену** (реальный отрендеренный DOM + реальный `../prod.css`), не рукописный
слой. Поддерживаются скиллом `refresh-templates` — растут и актуализируются пачкой, по релизам.

## Устройство

Каждый экран — папка `<screen>/`:
- `<slug>.html` — замороженный реальный DOM с провенанс-шапкой (из какой story / когда снято).
- `<slug>.view.html` — standalone-вьюер: тот же DOM под `../../prod.css`, открывается без React.
- `_manifest.json` — список состояний.
- `_gallery.html` — витрина всех состояний (для наборов компонентов, напр. `recipe-stepcard`).

`index.html` — общий индекс превью всех экранов.

## Что есть

- `recipes-list/` — список рецептов (populated).
- `settings-import/` — 4 раздела настроек + импорт (Окружение populated, остальные — реальные
  пустые состояния).
- `recipe-stepcard/` — 17 состояний StepCard («внутри рецепта»).

## Как пересобрать / актуализировать

```bash
bash ../tools/refresh-templates.sh [<git-ref>]
```
Подробности, добавление новых экранов и ловушки — в скилле `refresh-templates` (`.claude/skills/`).

⚠️ Файлы здесь **генерируются** из Storybook, не правь руками. Провенанс-шапка в каждом `<slug>.html`
показывает исходную story и дату. Отправная точка для «рисования по мотивам» — это не сюда:
шаблон = снимок прода, а не эскиз.
