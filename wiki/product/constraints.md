# Constraints — доменные ограничения

Жёсткие рамки продукта, которые ограничивают дизайн-решения. Учитывай в каждом сценарии.
Пополняй: когда в обсуждении задачи всплывает «так нельзя, потому что...» — фиксируй сюда.

## Test IT (TMS)
- Первая и основная интеграция. Кейсы приходят в формате Test IT — **мы не заставляем
  команды менять документацию**, читаем как есть.
- Российский рынок — переходный; долгосрочный фокус — международная экспансия.

## VNC / Visual Editor
- [[glossary|Visual Editor]] = браузер внутри VNC-десктопа. Отсюда ограничения по
  отзывчивости и взаимодействию — это не нативный веб-UI. (уточнить детали по задачам)

## Recipe
- Код генерится не напрямую, а через [[glossary|recipe]] — промежуточный слой ради
  поддерживаемости. Любой флоу правки теста идёт через рецепт.

## Приоритизация
- Фильтр любой фичи: *«приближает ли к первому платящему B2B-клиенту, оставаясь масштабируемым?»*
